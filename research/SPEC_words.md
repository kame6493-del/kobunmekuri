# 古文単語データの書き方(作業者向け)

アプリ「こぶんめくり」(大学受験の古文単語)の単語データを書く。置き場所は
`C:\Users\yuichi1\Downloads\こぶんめくり_2026-10-03\app\`(以下 APP)。

## 入力
- `APP\research\words_order.json` … 見出し語の一覧(rank=重要度順, w=見出し語, kanji=漢字表記, pos=品詞)
- `APP\research\candidates.json` … rank ごとの例文候補 {sid, work, loc, text, hit}。本文から機械で抜いた物なので、別の語や別の意味の用例も混じっている。
- `APP\research\sentences.jsonl` … 本文の全文(1行1文, {id, work, loc, text})。候補に良い文が無いときは Grep で自分で探す(漢字表記・活用形・音便も試す。例: こころもとなし→「心もとな」)。

## 出力
`APP\research\batches\<担当のファイル名>.json` に、JSON の配列で1語1オブジェクト。

```json
{
  "rank": 1,
  "w": "あはれなり",
  "kanji": "哀れなり",
  "pos": "形容動詞",
  "cat": "感動・趣",
  "means": ["しみじみと心を動かされる", "趣深い", "かわいそうだ"],
  "quiz": "しみじみと趣深い",
  "note": "感動して思わず出る「ああ」という声が語のもと。…(30〜180字)",
  "ex": {"sid": 12345, "text": "原文の連続した一部", "hit": "あはれなる", "tr": "自分で書いた現代語訳", "sense": 0}
}
```

- rank / w / kanji / pos は words_order.json のまま写す(見出しを変えたいときは変えずに "memo" に理由を書く)。
- cat: 次の中から1つ。4択の外れの選択肢を、意味の近い語から選ばないために使う。
  感動・趣 / 賞賛・すぐれる / 美・優雅 / かわいい・いとしい / 不快・嫌悪 / つらい・悲しい / 不安・心配 / 驚き・あきれ / 身分・高貴 / 程度・強調 / 時・時間 / 様子・状態 / 性格・態度 / 恋愛・人間関係 / 宗教・死・出家 / 言葉・音・手紙 / 行動・動作 / 心・思考 / 呼応・否定・疑問 / その他
- means: 意味を1〜4個、各20字以内。入試で問われる順(いちばん大事な意味を先頭)。古語辞典に載っている一般的な語義と合っていること。現代語と意味がずれる語は、ずれた古語の意味を必ず入れる。
- quiz: 4択で「正解」として出す短い意味(14字以内)。means の先頭の言い換えでよい。
- note: 解説を自分の言葉で(30〜180字)。語の成り立ち・覚え方・入試でのねらわれ方・対義語や紛らわしい語との違い など。事実として確かなことだけ書く。
- ex: 例文1つ。
  - sid は sentences.jsonl の id。text はその文の「連続した一部」を一字一句そのまま(句読点・かぎかっこも原文どおり。字を足したり直したりしない)。長い文は前後を切って 80字以内、できれば 15〜50字に。
  - hit は text の中で見出し語が出てくる部分(活用した形のまま。例「あはれなる」)。
  - tr は text 全体の現代語訳を自分で書く(4〜120字)。hit の部分は sense の意味で訳す。
  - sense は means の何番目(0始まり)の意味で使われているか。
  - 作品はなるべく枕草子・徒然草・源氏物語・竹取物語・更級日記・方丈記から。同じ作品に偏りすぎないように。
  - 見出し語と違う語(同じ字面の別語)を拾わないこと。意味が文脈から判断できる文を選ぶ。
  - どうしても見つからない語は ex を書かずに "noex": true と "memo" に探した語形を書く。

## 守ること
- 市販の単語帳・参考書・アプリ・辞書の文をそのまま写さない。意味は一般的な語義でよいが、言い回し・解説・訳は自分で書く。
- マークダウンの太字記法(アスタリスク2つ)と絵文字は使わない。
- 書き終えたら `python tools/validate.py research/batches/<ファイル名>.json` を APP で実行し、エラー 0 にしてから終える(Bash は `cd "/c/Users/yuichi1/Downloads/こぶんめくり_2026-10-03/app" && PYTHONIOENCODING=utf-8 python tools/validate.py ...`)。
- 書き込むのは自分の担当ファイルだけ。他のファイル・他のフォルダは変えない。
